04

Обо мне

Терпеть не могу отдавать результат, в котором сам не уверен. Если данные выглядят странно, полезу проверять, откуда они взялись, даже если это дольше. Лучше так, чем потом объяснять, почему в отчёте ерунда.

Мне нравится, когда задача поставлена в духе «надо разобраться», а не по пунктам. Так было с системой для Декаста: где-то API отдавал ошибки, где-то цифры не сходились, и приходилось придумывать обходные пути. В итоге всё работает без меня.

Новое осваиваю быстро, когда это нужно для дела. PostgreSQL, API и DataLens учил прямо по ходу проекта.

Вне работы играю в футбол за любительский клуб в Москве и делаю для команды сайт и бота.
